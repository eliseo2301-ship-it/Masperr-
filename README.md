# Masperr Publicidad & Impresión 🖨️🎨

> **"Hacemos realidad cualquier proyecto que tu marca requiera con la más alta calidad y precisión de México."**

Sitio web institucional, interactivo y de alto impacto visual para **Masperr Publicidad & Impresión**, líderes en México en publicidad, gran formato, offset e impresión industrial.

---

## 🌟 Características Principales

1. **Paleta de Colores Viva y Vibrante:** Estética inspirada en el espectro CMYK industrial (Cyan vivo, Magenta eléctrico, Amarillo vibrante y Azul marino profundo) con efectos de glassmorphism y microinteracciones fluidas.
2. **Hero Section de Alto Impacto:** Tipografía audaz, métricas institucionales (+15 años, +50,000 proyectos, 100% fidelidad de color) y llamadas a la acción directas hacia WhatsApp, Google Maps y Catálogo.
3. **Showcase Interactivo de Servicios:**
   - **Impresión Offset:** Tarjetas de presentación de lujo, volantes, trípticos, recetas médicas foliadas, notas de remisión y catálogos.
   - **Impresión Digital:** Soluciones express para tiros cortos y urgentes (hasta formato 30.5 x 45 cm).
   - **Gran Formato & Plotter:** Lonas publicitarias (Frontlit, Mesh, Backlight), vinil adhesivo, microperforado y rígidos (Coroplast, Estireno, Sintra).
   - **Displays & Puntos de Venta:** Muros expandibles (Backdrops), Roll Ups de aluminio reforzado, módulos demoset y sistemas desmontables.
4. **Muro Interactivo de Reseñas:** Testimonios de agencias de publicidad, empresas de retail y sector corporativo con calificación perfecta de 5 estrellas.
5. **Geolocalización & Mapa Interactivo:** Integración directa con Google Maps centrado en las coordenadas oficiales (`19.3873977, -99.1450275`) con botón de navegación asistida en un solo clic.
6. **Cotizador Exprés en Línea:** Generador interactivo de cotizaciones que redacta automáticamente un mensaje estructurado y detallado para enviar directo a WhatsApp.
7. **Asistente Virtual Maspi (Bot Flotante):**
   - Incorpora el **logotipo secundario** oficial como avatar.
   - Respuestas inteligentes para orientar en diferencias técnicas (Offset vs. Digital), materiales de plotter, displays y envío inmediato de la ubicación en Google Maps.
   - Derivación fluida con asesores humanos en WhatsApp.

## 🚀 Pila Tecnológica & Despliegue

- **Frontend:** React 18 + Vite
- **Estilos:** TailwindCSS con temas CMYK personalizados
- **Iconografía:** Lucide React
- **CI/CD & Hosting:** Configurado para **Render** vía `render.yaml` (Static Site)

### Ejecución Local

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
